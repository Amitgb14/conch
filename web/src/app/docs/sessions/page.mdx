# Sessions

conch lists the conversations your agents saved, per project, so you can resume, search or hand on any of them.

<FeatureGrid>
<Feature icon="sessions" title="Saved conversations" href="#saved-conversations">Every agent's conversations for a project, newest first.</Feature>
<Feature icon="reload" title="Resume" href="#resuming-a-session">Pick one up in its folder with the agent's own resume option.</Feature>
<Feature icon="chat" title="Share" href="#sharing-with-another-agent">Hand a conversation to another agent, here or on another machine.</Feature>
<Feature icon="signal" title="Interrupted runs" href="#interrupted-runs">Agents running at a reboot or crash come back by themselves.</Feature>

## Saved conversations

Select a project's **Sessions** section in the tree to list what Claude Code, Codex, Gemini CLI, OpenCode, Devin, Copilot CLI, Cline, Qwen Code, Goose, Pi, Grok, Cursor, Kilo Code and Antigravity CLI saved for it and its worktrees, with the agent, title, branch, what it used and its age.

```text
Sessions · api   enter resume · * star · / search · s share · d delete · a agent
4 saved · all agents · ⚠ 1 interrupted (I resumes all, x dismisses)

▸ ⚠ Claude Code  Fix the flaky login test  fix-login · interrupted · $1.40 · 2h
 ★· OpenCode     Refactor config                             main · $0.12 · 1d
  ● Codex        Add rate limiting             rate-limit · open · 3.0k out · 5m
  · Gemini CLI   Explain the auth flow                                main · 3d
```

**How:** `*` stars a session so it is listed first, `a` filters by agent, `d` deletes one after asking (Antigravity CLI has no delete of its own, so conch takes the conversation out of its list and moves its files to the trash), `R` reloads. `●` sessions are already open; `enter` shows their pane.

## Resuming a session

A session started on another of the agent's [accounts](/docs/agents#several-accounts) is listed with it (`Claude Code · work`) and resumes on that account.

`enter` (or a click on the selected row) resumes a session in its folder:

| Agent | Resume option |
| --- | --- |
| Claude Code | `claude --resume` |
| Codex | `codex resume` |
| Gemini CLI | `gemini --resume` |
| OpenCode | `opencode --session` |
| Devin | `devin -r` |
| Copilot CLI | `copilot --resume` |
| Cline | `cline --id` |
| Qwen Code | `qwen --resume` |
| Goose | `goose session --resume --session-id` |
| Pi | `pi --session` |
| Grok | `grok --resume` |
| Cursor | `cursor-agent --resume` |
| Kilo Code | `kilo --session` |
| Antigravity CLI | `agy --conversation` |

## Reading a conversation

`Y` opens a conversation to read and copy from; on an agent in the tree it opens the one it is writing now.

**How:** scroll with the wheel, `↑` `↓`, `pgup` `pgdn`, `g` and `G`. Drag over a part to copy it, `a` copies all, `esc` closes.

## Searching

`/` matches titles, agents, branches and session IDs as you type, then searches inside the conversations too. Every word must appear.

```text
/ cross compiler  2 found

▸ · Claude Code  Deploy fails on arm64  “…The cross compiler is missing. Install…”   main · 2d
  · Codex        Release script         “…needs a cross compiler for linux/arm64…”  main · 5d
```

**How:** `enter` keeps the results, `esc` clears the search, `ctrl+u` empties it. Devin conversations match by title and ID only.

## Sharing with another agent

`s` hands a conversation to a different agent so it picks up where the other left off:

- **Start an agent with it** in the session's folder.
- **Send to a running agent** in the project, as its next message.
- **On another machine** (`o`) — see below.

conch writes the conversation to `.conch/handoff/<agent>-<session>.md` and asks the agent to read it and continue. The [brain](/docs/brain) does the same from a plain request.

It opens with what is left of the plan, the files changed and the last error, then gives the turns: messages word for word, commands with the end of their output, reads, edits and tools as notes. Claude Code, Codex, Gemini CLI, Qwen Code and Copilot CLI are read this fully; for the rest it says it holds messages only.

To carry a running agent's conversation to another agent in the same pane, see [Switching agents](/docs/switching).

### On another machine

Pick a project on another online machine — or its **home folder**, for one with no project yet — then an agent to start or one already running there. Only the conversation moves, not the code: push the branch first if the agent needs the changes.

## Interrupted runs

After a reboot or a crash, the agents that were running come back by themselves when the server starts, each on its own conversation and account.

After `conch server stop`, or with `[agents] no_auto_resume = true`, they wait in Sessions marked `⚠ interrupted` for a week instead. So does one that can't come back, such as one whose worktree was removed.

**How:** `I` resumes all of them, `x` dismisses one.

They are also [kept in the tree](/docs/interface#agents-that-ended) where they were, as is an agent that crashed or was killed, with Resume on the row.
