# Agents

conch runs Claude Code, Codex, Gemini CLI, OpenCode and Devin in panes it owns, tracks what each is doing, and shows their usage and plan limits.

## Supported agents

| Agent | Install (no root) |
| --- | --- |
| **Claude Code** | `curl -fsSL https://claude.ai/install.sh \| bash` |
| **Codex** | `curl -fsSL https://chatgpt.com/codex/install.sh \| sh` |
| **Gemini CLI** | `npm install -g --prefix ~/.local @google/gemini-cli` (Node 20+) |
| **OpenCode** | `curl -fsSL https://opencode.ai/install \| bash` |
| **Devin** (preview) | `curl -fsSL https://cli.devin.ai/install.sh \| bash`, then `devin auth login` |

Devin is Cognition's `devin` CLI. A Devin pane that needs an answer looks idle.

## Two tiers

- **Supported** — the five above, with their saved conversations in the [Sessions](/docs/sessions) view.
- **Runs here** — described by a manifest: conch starts and recognises it, but does not read its sessions.

conch ships manifests for **Aider**, **Amp**, **Cursor CLI**, **Grok**, **Kilo Code** and **Pi**, marked with a square rather than a circle.

**How:** add your own, then reload the server.

```sh
conch agent add robo -command robo -label "Robo Coder" \
  -prompt '--message {prompt}' -resume '--resume {id}' -resume-last --continue
```

That writes `~/.config/conch/agents/robo.toml`.

## Starting agents

`c` asks which agent to start at the selected row; `c` `enter` starts the default (Settings → Agents). Missing agents can be installed from the same list; `A` starts or installs any agent.

**From a shell:** `conch new -agent claude -cwd DIR`, `conch agent status`, `conch agent install NAME` (add `-m MACHINE` for a remote machine).

<Callout type="note">

conch never edits an agent's own configuration or answers its trust prompts for you.

</Callout>

## Agent states

<AgentStates />

| State | Meaning |
| --- | --- |
| `⠋` working | the agent is busy |
| `!` waiting | blocked on you: a permission, trust or other question |
| `✓` done | finished while you were looking elsewhere |
| `○` idle | waiting for a prompt |
| `✗` failed | its last request ended with an error; cleared by the next prompt |

**How:** `!` in the tree, or `ctrl+b !` in a pane, jumps to the next agent waiting for you.

### How the state is decided

Most reliable first:

1. **The program's own report** ([OSC 7501](https://mitchellh.com/writing/program-status-osc7501)), from Claude Code 2.1.295 and later.
2. **Hooks**, added with `--settings`; yours still run.
3. **Screen rules** over the bottom of the screen.
4. **Foreground process**: a pane is an agent only while the agent is in front.

**How:** `conch agent explain p1` shows the evidence behind a state.

### conch reports its own state too

conch sends one OSC 7501 report to your terminal — `blocked` while any agent waits on you — for the terminal's tab to show.

**How:** it is off inside tmux and screen; `CONCH_STATUS=0` turns it off anywhere, `1` turns it on.

## Agents working together

An agent can start and prompt another. See [Agents working together](/docs/agents-together).

## Broadcast

`B` types one message into several panes and submits it: a prompt to every agent in a project, or `git pull` in every terminal. The list follows the tree's selection; agents waiting for an answer, and terminals in a mixed list, start unticked.

**How:** type the message, `tab` to the list, then `space` ticks, `a` ticks all, `t` all terminals, `e` every machine. `enter` asks to confirm; `n` goes back.

## Token usage

Agent panes show usage in their title: `ctx 45k/200k · out 12k · $0.42`.

**ctx** is the context window used now, **out** the output tokens this session, **$** the cost when the agent reports one.

## Plan limits

<Shot name="desktop-limits" alt="Claude plan limits shown as bars with their reset times" caption="Plan limits and when each window resets." />

For Claude subscriptions the status bar shows the current windows, e.g. `Claude 5h 42% · 7d 18%`, amber from 70% and red from 90%. Codex's windows come from its session files; API-key logins have none.

**How:** click it for reset times. conch alerts once at 80% and again at 95% (see [notify](/docs/configuration#notify)).
