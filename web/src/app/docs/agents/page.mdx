## Supported agents

| Agent | Install (no root) |
| --- | --- |
| **Claude Code** | `curl -fsSL https://claude.ai/install.sh \| bash` |
| **Codex** | `curl -fsSL https://chatgpt.com/codex/install.sh \| sh` |
| **Gemini CLI** | `npm install -g --prefix ~/.local @google/gemini-cli` (Node 20+) |
| **OpenCode** | `curl -fsSL https://opencode.ai/install \| bash` |
| **Devin** (preview) | `curl -fsSL https://cli.devin.ai/install.sh \| bash`, then `devin auth login` |
| **Copilot CLI**, **Cline**, **Qwen Code**, **Goose** | `c` → install |

A Devin pane that needs an answer looks idle.

## Two tiers

- **Supported** — the nine above, with their saved conversations in the [Sessions](/docs/sessions) view.
- **Runs here** — from a manifest: conch starts and recognises it; only Pi, Grok, Cursor, Kilo Code and Antigravity CLI list sessions.

conch ships manifests for [fourteen more](/docs/cli#the-agents-conch-knows), marked with anything but a circle.

**How:** add your own, then reload the server.

```sh
conch agent add robo -command robo -label "Robo Coder" \
  -prompt '--message {prompt}' -resume '--resume {id}' -resume-last --continue
```

That writes `~/.config/conch/agents/robo.toml`.

## Starting agents

`c` asks which agent to start at the selected row; `c` `enter` starts the default (Settings → Agents). Missing agents install from there or Settings → Agents; `A` starts or installs any agent.

**From a shell:** `conch new -agent claude -cwd DIR`, `conch agent status`, `conch agent install NAME` (add `-m MACHINE` for a remote machine).

<Callout type="note">

conch never edits an agent's own configuration or answers its trust prompts for you.

</Callout>

## Agent states

<AgentStates />

| State | Meaning |
| --- | --- |
| `⠋` working | the agent is busy |
| `!` waiting | blocked on you: a permission, trust or other question |
| `✓` done | finished while you were looking elsewhere |
| `○` idle | waiting for a prompt |
| `✗` failed | its last request ended with an error; cleared by the next prompt |

**How:** `!` in the tree, or `ctrl+b !` in a pane, jumps to the next agent waiting for you.

### Left running in the background

An idle agent that left a dev server or a background shell running shows **⟳2**, with each listed under it. MCP servers and other helpers don't count.

**How:** `m` on a job → **Stop it**.

### How the state is decided

Most reliable first:

1. **The program's own report** ([OSC 7501](https://mitchellh.com/writing/program-status-osc7501)), from Claude Code 2.1.295 and later.
2. **Hooks** (Claude Code, Gemini CLI, Codex); yours still run.
3. **Screen rules** over the bottom of the screen.
4. **Foreground process**: a pane is an agent only while the agent is in front.

**How:** `conch agent explain p1` shows the evidence behind a state.

### conch reports its own state too

Your terminal's tab shows `blocked` while any agent waits on you. `CONCH_STATUS=0` turns it off.

## Agents working together

An agent can start and prompt another. See [Agents working together](/docs/agents-together).

## Broadcast

`B` sends one message to several panes: a prompt to every agent in a project, or `git pull` in every terminal.

**How:** type it, `tab` to the list, `space` ticks, `enter` sends.

## Token usage

Agent panes show usage in their title: `ctx 45k/200k · out 12k · $0.42`.

Context used, output tokens, and cost where the agent reports one.

## Plan limits

The status bar shows Claude's and Codex's windows, e.g. `Claude 5h 42% · 7d 18%`, amber from 70% and red from 90%.

**How:** click it for reset times. conch alerts once at 80% and again at 95% (see [notify](/docs/configuration#notify)).

## Several accounts

A work and a home subscription of Claude Code or Codex side by side.

1. **Add one:** `conch account add claude work`.
2. **Sign in once:** `conch new -agent claude -account work`, then `/login`.
3. **Pin a folder:** `conch account pin ~/src/acme work`; agents started there use it.
4. **Or per task:** `conch task -account home "Fix the flaky test"`.
5. **Failover:** `conch account failover 90`; a new agent skips an account past 90%.

`conch account list` or Conch.app's **Settings → Agents → Agent accounts** shows each one's limits. Sessions resume on their own account. A new account starts empty: copy in your `CLAUDE.md` and skills. See [Agent accounts](/docs/cli#agent-accounts).
