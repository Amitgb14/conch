## The window

The sidebar is conch's tree; tabs and splits work as in the TUI.

**Windows:** `⌥⌘N`, or **Open in New Window** on a workspace or project.

**Background:** a scene, or [your own](/docs/configuration#scenes-of-your-own): **Settings → Mac App → Background**.

**How:** click a row, right-click for more. ⌘. finds a waiting agent; ⌃⌘S hides the sidebar.

**Teams:** right-click an agent → **Team**, or drag it to a [team](/docs/configuration#teams).

## Settings

**How:** ⚙ in the status bar, or ⌘,. **View → Theme** and **View → Style** change the look.

## Panes drawn by Ghostty

A pane sized by another window is letterboxed.

**How:** **Take it**, or type, to size it here.

## The scratch layer

A shell floating over the splits.

**How:** ⌥Space shows or hides it; ⌥⌘↩ docks it, ⌥⌘T makes it a tab.

## A branch's changes

A branch opens in a tab. Tick hunks, then **Commit**; **✦ Write** drafts a message; **+** leaves a note.

**How:** ⋯ holds **Push**, **Merge…** and **Open Pull Request**.

## Agent setup

What each agent loads in a checkout.

**How:** **Agent setup** on a project's menu.

## Left running

An agent that left a server running shows *idle · 2 running*.

**How:** hover for each command; click to stop one.

## Answering an agent without opening it

Each waiting agent is a card under **Needs you**, its choices as buttons.

**How:** click a choice to answer, or the card to open it.

## Files and sessions

**Files** edits the checkout; **Sessions** resumes saved conversations.

| Keys | |
| --- | --- |
| `⌘S` | save |
| `⌘P` | go to a file |
| `⇧⌘F` | search the project |
| `⌥⌘F` | find and replace |
| `⌘I` | edit with an agent |

## Workbench

An agent's files, terminal, chat and browser (🌐) in one tab.

**How:** ⌥⌘B, or right-click an agent → **Open Workbench**; ⌥⌘1–⌥⌘5 pick a layout.

**The chat:** attach files with ⇧⌘A. Off: `[app] chat = false`.

## Browser tabs

A web page in a tab, a split or a Workbench, with tabs of its own.

**How:** ⇧⌘B, ⌥⌘D, or an agent's `:3000 ↗`. In a page: ⌘T, ⌘W, ⇧⌘T, ⌘L, ⌃Tab, ⌘F, ⌘+, ⌥⌘I. Right-click a tab to duplicate it or move it to its own pane; hover it, or ⋯ → **Browser Memory**, for its memory.

## Commits

Agents' branches, conflicts, **CI**, **Autopilot**.

**How:** **Commit Graph** on a project's or branch's menu.

## Starting agents and tasks

**How:** **File → New Task…** (⌘N), **File → Start Agent** (⇧⌘N), **Add Project…** (⌘O).

## System Monitor

CPU, memory, disk and the heaviest processes, on any machine conch reaches.

**How:** `⌥⌘M`, or the expand icon on the `▁▃▆` monitor.

## Tickets

Every project's issues and tickets.

**How:** `⇧⌘I`. Setting up a tracker: [Tickets](/docs/tasks#tickets).

## Keys

| Keys | |
| --- | --- |
| `⌘K` | search |
| `⌘T` / `⌘D` | new terminal tab / split |
| `⇧⌘↩` | zoom the focused split |
| `⌘F` | find in the pane |
| `⌥⌘N` / ``⌘` `` | new window / next window |
| `⌘W` | close the split |
| `⌘1`–`⌘9` | go to a tab |
| `⌘0` | the sidebar takes the keyboard |
| `⌘/` | every keyboard shortcut |

The TUI's `ctrl+b` [prefix keys](/docs/configuration#rebinding-the-keys) work too.

## Installing the beta

Download the `.dmg` from the [releases](https://github.com/Amitgb14/conch/releases); Apple Silicon, macOS 14+.

**How:** drag it to **Applications**; **Conch → Check for Updates…** updates it.

## Building it

```sh
# needs Xcode's Command Line Tools and Go; Ghostty also Xcode 26 and Zig
macos/ghostty.sh                 # Ghostty's library → macos/vendor
macos/bundle.sh                  # → macos/build/Conch.app
```
