## The window

The sidebar is conch's tree; tabs and splits work as in the TUI.

**Windows:** `⌥⌘N`, or **Open in New Window** on a workspace or project.

**How:** click a row to open it, right-click for its menu. ⌘. finds the next waiting agent, ⌃⌘S hides the sidebar.

## Settings

conch's settings, including **Skills & MCP Servers**.

**How:** ⚙ in the status bar, or ⌘,. **View → Theme** and **View → Style** change the look.

## Panes drawn by Ghostty

Each pane runs [`conch attach`](/docs/cli#attach), drawn by Ghostty. A pane sized by another window is letterboxed.

**How:** **Take it**, or type, to size it here.

## The scratch layer

A shell floating over the splits.

**How:** ⌥Space shows or hides it, ⌥⌘↩ docks it as a split, ⌥⌘T makes it a tab.

## A branch's changes

A branch opens in a tab: **Overview · Changes · Graph**. Tick hunks, then **Commit**; **✦ Write** drafts a message; **+** on a line leaves a note.

**How:** ⋯ holds **Push**, **Merge into main…**, **Open Pull Request** and **Delete Branch…**.

## Agent setup

What each agent loads in a checkout.

**How:** **Agent setup** on a project's menu.

## Left running

An agent that left a dev server running shows *idle · 2 running*.

**How:** hover it for each command; click it to stop one.

## Answering an agent without opening it

Each waiting agent is a card under **Needs you**, its choices as buttons.

**How:** click a choice to answer, or the card to open it.

## Files and sessions

**Files** opens the checkout in an editor; **Sessions** lists saved conversations to search and resume.

| Keys | |
| --- | --- |
| `⌘S` | save |
| `⌘P` | go to a file |
| `⇧⌘F` | search the project |
| `⌥⌘F` | find and replace |
| `⌘I` | edit with an agent |

## Workbench

An agent's files, a terminal and its chat in one tab.

**How:** ⌥⌘B, or right-click an agent → **Open Workbench**; ⌥⌘1–⌥⌘4 pick a layout.

**The chat** is the agent's conversation as messages. Attach files with 📎 (⇧⌘A), a paste, a drop or `@`; **Stop** reads Stopping… at once. Off with `[app] chat = false`.

## Commits

The project's history as a graph.

**How:** **Commit Graph** on a project's or branch's menu.

## Starting agents and tasks

A task gives an agent a prompt on a branch of its own.

**How:** **File → New Task…** (⌘N), **File → Start Agent** (⇧⌘N), **Add Project…** (⌘O).

A plain folder is offered **Initialize Git** first.

## System Monitor

The whole machine — CPU, memory, disk and its heaviest processes — on any machine conch reaches. It only shows.

**How:** `⌥⌘M`, or the expand icon on the `▁▃▆` monitor.

| Keys | |
| --- | --- |
| `⌘K` | search |

| `⇧⌘↩` | zoom the focused split |

## Installing the beta

Download `Conch_<version>_macos_arm64.zip` from the [releases](https://github.com/Amitgb14/conch/releases); it needs Apple Silicon and macOS 14+.

**How:** unzip it into **Applications**; **Conch → Check for Updates…** updates it.

## Building it

Needs Xcode's Command Line Tools and Go; Ghostty, Xcode 26 and Zig.

```sh
macos/ghostty.sh                 # Ghostty's library → macos/vendor
macos/bundle.sh                  # → macos/build/Conch.app
```
