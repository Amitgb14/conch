## The window

The sidebar is conch's tree: each machine, its projects, agents, branches and terminals. Tabs and splits are as in the TUI.

**How:** click a row to open it, right-click for its menu. ⌘K searches, ⌘. goes to the next waiting agent, ⌃⌘S hides the sidebar.

## Settings

conch's settings, including **Skills & MCP Servers**.

**How:** ⚙ in the status bar, or **conch → Settings…** (⌘,). **View → Theme** and **View → Style** change the look.

## Panes drawn by Ghostty

Each pane runs [`conch attach`](/docs/cli#attach), drawn by Ghostty. A pane sized by another window is letterboxed.

**How:** click **Take it**, or type in the pane, to size it to this window.

## The scratch layer

A shell floating over the splits, in the project on screen.

**How:** ⌥Space shows or hides it, ⌥⌘↩ docks it as a split, ⌥⌘T makes it a tab.

## A branch's changes

A click on a branch opens it in a tab: **Overview · Changes · Graph**. Tick files or hunks and **Commit**; **✦ Write** drafts the message. Hover a line and press **+** to leave a note for the agent or a pull request comment.

**How:** ⋯ holds **Push**, **Merge into main…**, **Open Pull Request** and **Delete Branch…**.

## Agent setup

What each agent loads in a checkout: instructions, skills and MCP servers.

**How:** **Agent setup** on a project's menu.

## Answering an agent without opening it

Every waiting agent is a card under **Needs you**, with its question and its choices as buttons.

**How:** click a button to answer, or the card to open the agent.

## Files and sessions

The **Files** row opens the checkout in an editor; the **Sessions** row lists saved conversations to search and resume.

| Keys | |
| --- | --- |
| `⌘S` | save |
| `⌘P` | go to a file |
| `⇧⌘F` | search the project |
| `⌥⌘F` | find and replace |
| `⌘I` | edit with an agent |

## Workbench

An agent's files, a terminal and its chat in one tab.

**How:** ⌥⌘B, or right-click an agent → **Open Workbench**. ⌥⌘1–⌥⌘4 pick the IDE, Chat First, Agent or JetBrains layout.

## Browser tabs

A web page in a tab beside the agents.

**How:** **File → New Browser Tab** (⇧⌘B).

## Commits

The project's history as a graph.

**How:** **Commit Graph** on a project's menu, or **Show in Commit Graph** on a branch's.

## Starting agents and tasks

A task gives an agent a prompt on a branch of its own.

**How:** **File → New Task…** (⌘N); **File → Start Agent** (⇧⌘N) starts one where the focused pane is; **Add Project…** (⌘O).

## Keys

| Keys | |
| --- | --- |
| `⌘K` | search |
| `⌘T` / `⌘D` | new terminal tab / split |
| `⇧⌘↩` | zoom the focused split |
| `⌘F` | find in the pane |
| `⌘W` | close the split; the pane keeps running |
| `⌘1`–`⌘9` | go to a tab |
| `⌘0` | the sidebar takes the keyboard |
| `⌘/` | every keyboard shortcut |

The TUI's prefix keys work too: `ctrl+b`, then a key from the [prefix table](/docs/configuration#rebinding-the-keys).

## Installing the beta

Download `Conch_<version>_macos_arm64.zip` from the [GitHub release page](https://github.com/Amitgb14/conch/releases). It needs Apple Silicon and macOS 14 or later.

**How:** unzip it, drag **Conch.app** into **Applications** and open it. To update, replace the app.

## Building it

Needs the Xcode Command Line Tools and Go; Ghostty needs Xcode 26 and Zig.

```sh
macos/ghostty.sh                 # Ghostty's library → macos/vendor
macos/bundle.sh                  # → macos/build/Conch.app
```
