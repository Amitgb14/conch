# Keys and mouse

Every key binding in the TUI, grouped by where it applies. Press `?` in conch to see them all; the prefix `ctrl+b` can be changed with `[keys] prefix` in [config.toml](/docs/configuration).

## Tree

| Key | Action |
| --- | --- |
| `↑↓` `jk` | move |
| `←→` `hl` | fold |
| `space` | toggle |
| `enter` | open pane / view changes |
| `/` | filter (`/ !` keeps only the agents waiting for you) |
| `!` | next agent waiting for you |
| `Q` | [review queue](/docs/interface#review-queue): what needs a decision, across every machine (`v` checks a row, `o` opens the check's output, `x` dismisses it) |
| `B` | [broadcast](/docs/agents#broadcast) a message to the agents and terminals of the selection |
| `f` | [files](/docs/interface#files): browse the selected project's checkout, or a branch's worktree |
| `o` | open PR |
| `b` `$` | on a branch: the [git window](/docs/interface#git-panel) — any git command, the everyday ones behind `tab`, and messages for the agent working there |
| `T` | on a branch: [move its worktree to another machine](/docs/remote-machines#moving-a-worktree-to-another-machine) |
| `y` | copy |
| `m` | menu |
| `?` | all keys: `↑↓` `jk` `pgup` `pgdn` `g` `G` and the wheel scroll the list, `←→` `hl` (or shift+wheel) pan across long lines, any other key or a click closes it |
| `q` | detach |

## Create

| Key | Action |
| --- | --- |
| `t` | task: a branch and worktree in a git project; on a machine, or a folder that isn't a repository, an agent with the prompt right there |
| `c` | default agent here |
| `A` | start or install any agent |
| `n` | terminal here |
| `H` | [ssh to a host](/docs/interface#ssh-sessions) from this computer, with extra ssh options if you need them; asks whether to save the host (default no) |
| `e` | on a saved ssh host or an ssh session: edit its host, name, [folder](/docs/interface#ssh-folders) and ssh options |
| `K` | on a saved ssh host or an ssh session: set up login without a password — copies your public key to the host (makes `~/.ssh/id_ed25519` first if you have no key) |
| `a` | on a folder of `SSH`: add a saved host to it, without connecting |
| `P` | [pair a phone](/docs/phone#pair-a-phone) with this computer: a QR code and a one-time code for `conch web`, for a phone that may type into terminals too; in it `v` / `r` / `f` give a new code for view, reply or full, `y` copies the link and `c` the code (or click them), `s` starts `conch web` when it isn't running. 🌐 in the status bar opens it too |
| `a` | add project |
| `M` | add a machine: **Over ssh…**, or **New sandbox…** and a provider ([sandboxes](/docs/sandboxes)) |
| `r` | rename an agent, terminal or machine |
| `x` | close / remove (a branch: its worktree, or the branch itself once that is gone) |
| `R` | refresh git and PRs, or reconnect a machine |

Other keys on tree items:

| Key | Action |
| --- | --- |
| `i` | [agent setup](/docs/tasks#agent-setup) for a project, branch or pane. In it: `s` gives the other agents this one's setup ([one setup, every agent](/docs/tasks#one-setup-every-agent)), `u` undoes that, `S` installs or removes conch's own skill for the agent whose tab is open, `c` copies missing local files, `f` edits the patterns |
| `F` | [local file patterns](/docs/tasks#local-files-in-worktrees) for a project |
| `W` | [clean up a project's worktrees](/docs/tasks#cleaning-up-worktrees) |
| `S` | [summarise](/docs/brain#summaries) an agent |
| `C` | [install Claude Code](/docs/remote-machines#claude-code-on-a-machine) on a machine |
| `:` | [ask the brain](/docs/brain) |
| `,` | [settings](/docs/interface#settings) |
| `v` / `s` / `O` | open the selected item in a split right / below / a new tab |

## Files

| Key | Action |
| --- | --- |
| `↑↓` `jk`, `pgup` `pgdn`, `g` `G` | move |
| `enter` `l` `→` | open a folder, or show a file (below 100 columns the preview takes the split; `esc` goes back) |
| `h` `←` | fold the folder, or go up to the one it is in |
| `/` | find by name in what has been loaded (`enter` keeps, `esc` clears) |
| `a` | type the file's path into the agent working in this checkout |
| `y` | copy the file's path |
| `d` | the file's diff, in its branch's changes |
| `e` | open it in `$EDITOR` in a new terminal, on its machine |
| `.` / `i` | show dotfiles / files git ignores |
| `w` | the project's next checkout: the main one, then each worktree |
| `r` | read the checkout again |
| `esc` `q` | back to the tree |

Click a line to select it and again to open it; the wheel moves the selection, or scrolls the preview under the pointer; click a folder in the path above the list to go back up to it.

## Splits and tabs

| Keys | |
| --- | --- |
| `ctrl+b %` or `v` / `ctrl+b "` or `-` | split right / down (beside a terminal or agent, the new split starts a shell in its folder; otherwise it waits for you to open something) |
| `ctrl+b ←→↑↓`, `o`, `;` | move focus between splits: by direction, to the next, to the last one focused |
| `ctrl+b {` / `}` | swap the split with the previous / next |
| `ctrl+b q` | show split numbers; press a number while they show to focus that split |
| `ctrl+b space` | next layout: even-horizontal, even-vertical, main-horizontal, main-vertical, tiled (`ctrl+b alt+1`–`alt+5` pick one) |
| `ctrl+b ctrl+arrow` / `alt+arrow` | resize by 1 / 5 cells; press the arrow again within half a second to keep resizing |
| `ctrl+b x` | close the split; an agent or terminal in it ends, after you confirm |
| `ctrl+b c`, `n`, `p`, `0-9`, `l` | new tab with a terminal in it, next, previous, go to, last tab (among the tabs listed for the tree selection) |
| `ctrl+b <` / `>`, `.` | move the tab left / right, or to a position you type (among the tabs listed) |
| `ctrl+b w` | pick any tab or split, grouped by project and CLI, with each split's branch or folder and agent state |
| `ctrl+b &`, `,` | close, rename tab |
| `ctrl+b =`, `z` | equalize splits, zoom |
| `ctrl+b r` | draw the selected pane's screen again, when a program left stale text behind (a partial redraw after the pane changed size). conch clears its copy of the screen — without keeping the stale one in the scrollback — and tells the program its size changed, so nothing is typed into it; a program that doesn't repaint (a plain shell) shows its prompt again on the next keypress. Also in the pane menu, and `conch redraw ID` from a shell. |
| `ctrl+b S` | type into every agent and terminal in the tab at once, like tmux's `synchronize-panes`; their borders turn amber and the status bar shows `SYNC`. Press it again to stop. |
| `ctrl+b d` | detach (agents keep running) |
| `ctrl+b !`, `:` | jump to the next agent waiting for you, ask the brain |
| `v` / `s` / `O` in the tree | open the selected item in a split right / below / a new tab |

These follow tmux's default bindings; `ctrl+b 1` is the first tab and `0` the tenth. `ctrl+b !` jumps to the next agent waiting for you instead of breaking a pane out.

## Scroll mode

`ctrl+b [` (or `ctrl+b pgup`) enters scroll mode with a cursor.

| Key | Action |
| --- | --- |
| `↑↓←→` / `hjkl` | move the cursor (scrolling at the edges) |
| `0` / `$` | line start / end |
| `pgup` / `pgdn` | page |
| `g` | oldest line |
| `/` / `?` | search up (back through the history) / down; `enter` finds, `esc` cancels, `enter` alone repeats the last search |
| `n` / `N` | next match the same way / the other way; a search that reaches an end goes on from the other |
| `v` or `space` | start a selection |
| `y` or `enter` | copy the selection |
| any other key | return to live |

## Git panel

| Key | In the git panel |
| --- | --- |
| `enter` | run what is typed: git's arguments (a leading `git` is optional), or a message for the agent |
| `↑↓` | earlier commands |
| `tab` | show the everyday actions in place of the output; each has its own key, the arrows move and `enter` runs one; `tab` or `esc` goes back |

| `pgup` `pgdn` | scroll the output (the wheel too) |

## Mouse

- Click to select; click a selected folder (or its arrow) to fold. A click on a branch shows its changes; `b` or `$` opens the [git window](/docs/interface#git-panel) over them.
- Double-click to open.
- With `[ui] hover` on (Settings → Theme), the row or tab under the pointer is tinted before you click it, a link in a pane is underlined, and in Ghostty or kitty the pointer becomes a hand over one. It asks the terminal to report every pointer move rather than only drags — a message per cell crossed — so it is off until asked for, and a program in a pane still receives only the mouse it asked for.
- Right-click for a context menu. On an agent's pane it holds **Prompt…**, which sends that agent its next message and tells you when the work it started ends (see [Agents working together](/docs/agents-together)).
- Wheel to scroll; over a pane, the wheel scrolls back through its history.
- Drag the sidebar's edge to resize, or a border between splits.
- A pane with history keeps a bar on its right edge: how far back the screen is, and how much there is. Drag it to go there directly, rather than turning the wheel through a long conversation. Borders shared with another split still resize — the outer edge is the one that scrolls.
- Drag a row into a **folder** of its own section, or back out onto the section itself to leave it. The row under the pointer is marked while you hold; a folder of another section does not take it, since a pane listed under Terminals belongs in a Terminals folder.
- With the tree [grouped by tab](/docs/interface#grouped-by-tab), drag an agent or terminal **row in the tree** onto a tab's section to put it in that tab — the same move, reached from the tree. A pane that was in another tab leaves it, and that tab closes if it was the last split in it; one that was in no tab is opened there. The section under the pointer is marked while you hold; let go anywhere else and nothing moves.
- Drag a split by its title onto a **tab** in the bar to move it into that tab: it leaves the split it was in, which closes as closing a split does, and the tab it was dropped on is the one shown afterwards. A tab that held nothing else goes with it. Dropped on the **`+`** it goes to a tab of its own, beside the one it left — conch has no "break this split out" key, since `ctrl+b !` jumps to the next agent waiting. The tab or `+` under the pointer is marked while you hold. Let go on the space between tabs and nothing moves; nor does the `+` take the only split of a tab, which is already a tab of its own.
- Drag a split by its title onto another split to swap the two — the layout stays as it is, so the halves keep the sizes you gave them, and each view keeps what it was holding (a diff its scroll, a file explorer its folder). While you hold, the split being carried is marked and so is the one it would land on; after you let go, both stay marked for a moment, since two panes full of text swapping is otherwise hard to see happen.
- Drag a tab along the bar to reorder it — the bar reorders under the pointer as you go, and letting go anywhere keeps it (`ctrl+b < >` and `ctrl+b .` do the same from the keyboard).
- Drag across a pane or a page (a diff, a file, a list) to select and copy; double-click copies a word in a pane, triple-click the whole line (without the blanks it is padded to). A line too long for the pane is several rows on screen but one line when copied: conch joins the rows it wrapped over, so a command pasted into a shell runs as one command. Dragging past the top or bottom edge, or turning the wheel mid-drag, scrolls and keeps selecting.
- Drop files on a remote machine's pane to upload them there and paste their paths there.
- **Click a link an agent printed** to open it in the browser; it is copied as well. Inside an agent's own interface — anything that asked for the mouse — hold **alt** (or ctrl), since plain clicks belong to the program. A link wrapped over several rows opens whole. `ctrl+b u` still lists every link on the screen, which is the way to reach one that has scrolled away.
- Click `⚑ N waiting · N done` to jump to the next agent that needs you.
- Click the plan chip (`Claude 5h 42% · 7d 18%`) for a window with all of it, at the bottom right beside the chip: every agent that has reported on every machine, and **every window it named** — the five-hour, the week, a weekly allowance for one model, a spend limit — each with a bar that fills as it opens, the percentage, when it resets (both how long and at what time), when the agent last said so, and what conch itself has seen that machine spend — which counts **whole conversations, as each agent counts them**, with the prompt, cache-read, cache-write and output tokens kept apart. That is not the same as the agent's own usage panel, which counts the run it is on: a conversation days old reads as hundreds of dollars here and a few in a panel opened a minute ago, and both are right. Click it again or press `esc` to close.

Clicks inside a pane go to programs that use the mouse. Hold shift (option in iTerm2) to select text with your terminal, or set `[ui] mouse = false`.
