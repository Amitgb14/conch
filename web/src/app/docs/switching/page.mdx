# Switching agents

In the TUI or Conch.app, open the agent's menu (`m`, or right-click its row) and pick **Switch Agent ▸**, then an agent. From a shell, `conch agent switch ID AGENT` (or `-preview` first) carries a running agent's conversation to another agent, which resumes it **in the same pane**: same id, tab, branch and row. Use it when a plan runs out, or for a second opinion without retelling the story.

- **Claude Code ↔ Codex:** the target resumes it as a session of its own, with the history. Codex imports a Claude Code session itself where it can (Codex 0.126 and later, a session under `~/.claude/projects`). Otherwise conch writes the session.
- **Any other agent:** it starts with the [handoff document](/docs/sessions#sharing-with-another-agent) as its first message. An agent that cannot be given one is refused.

**The card** says what crosses, what fits and what is left behind, then switches after five seconds: **Switch Now** (enter), **Choose…** (`c`) or **Cancel** (esc). A turn under way is waited for, and the card says so. Afterwards a line over the pane says where the conversation came from, with **Switch back**; `×` hides it.

**At a plan limit:** an agent its plan stopped moves to another account of its own first (see **Moving a running agent** under [`conch agent`](/docs/cli#agent)). Only when no account of that agent has room is another agent offered, on a card at the foot of the pane: how full each account is and when the first resets, what would cross, and **Continue in Codex** (enter), **Wait for the reset** (`w`) or **Choose…** (`c`). Claude Code is offered Codex and Codex Claude Code, as long as it is installed and has room itself. To have it done without asking, name the agent in `config.toml`:

```toml
[agents]
switch_at_limit = "codex"  # "" (the default) asks; "wait" offers nothing
```

Then the card counts down a few seconds with **Continue Now** and **Cancel**, and the server switches by itself, so it happens with no TUI or app open. An agent that is not installed, is out of plan too, or cannot take a first message is never switched to unasked: the card says why. It is never silent: the switch is said, and the pane's banner offers **Switch back** once the first agent has room again. In Conch.app it is **Settings › Agents › When out of plan**. `[agents] no_move_at_limit` turns off only the move: with it, an agent waits on its account when another account has room, and is still offered another agent when none has.

**What crosses:** messages word for word; commands as the target's own shell tool, with their output; reads, edits and other tools as one-line notes; the latest plan. Thinking and reasoning do not cross. A conversation too long for the target's context keeps its first request and its latest turns whole, and the turns between are shortened.

**Safely:**

- Never mid-turn. Without `-now` it waits for the turn to end, and up to ten minutes for background commands; `-cancel ID` calls it off.
- Each session is written to a scratch folder and read back first. If that fails, the document is handed over instead, and the result says why.
- Only new files are written, and the source session is never touched, so switching back always works: it is just another switch.
- `-preview` says what would cross; `-undo RECORD` removes what a switch wrote, keeping a file the agent has written to since.

Agents can do the same through the `switch` tool of `conch mcp`, on agents they started.
