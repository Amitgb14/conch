# Introduction

conch is a terminal orchestrator for AI coding agents: a background server owns their terminals, so they keep working when you close the UI.

## Is conch for you?

- **Yes**, if you run several agents at once — on different branches, worktrees or machines — and need to know which one is waiting on you.
- **No**, for one agent in one repo: run the agent's own CLI.
- **No**, for unattended swarms: nothing runs until you confirm.
- macOS and Linux only; on Windows, use WSL.

What it does that other tools leave to you is on [Why conch](/docs/why).

## How it fits together

Each machine runs one conch **server** that owns every pane. Running `conch` opens the **TUI**, a client of that server; press `q` to detach, and run `conch` again to pick up where you left off.

<Architecture />

[Conch.app](/docs/mac-app) and [your phone](/docs/phone) are clients of the same server.

## The tree

Machines, then their projects, then each project's branches, agents and terminals. See [The interface](/docs/interface).

```text
MACHINES
▾ ● local                        ⠋1 ⚑1
  ▾ ▤ Workspace                      1
    ▾ ◆ api                      ⠋1 ⚑1
      ▾ Branches                     7
          ● main                    +1
          ◇ conch/add-health-check  ⠋ ↑3
      ▾ Agents                       2
          ⠋ Add health check   conch/add-health-check
          ! Fix flaky tests    fix/flaky
      ▾ Terminals                    1
          › dev-server         main
  ▾ ❯ CLI                          1
    ▾ Terminals                    1
        › zsh
```
