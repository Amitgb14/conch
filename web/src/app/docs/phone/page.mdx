# Phone

`conch web` lets a phone see your agents, reply to one, and answer the question it is waiting on.

## What you need

- **Tailscale** on the laptop and the phone, signed in to the same account — or a [relay](#through-a-relay) of your own.
- **HTTPS** in front, which `tailscale serve` gives you.
- **conch** on the laptop.

## Start it

In the TUI, **⚙ Settings → Web**: set the address phones open, then **Start conch web**. Or from a terminal:

```sh
tailscale serve --bg http://127.0.0.1:8722
conch web -url https://laptop.tail1234.ts.net
```

`conch web stop` ends it. Every flag is on [Command line](/docs/cli#web).

## Pair a phone

Run `conch web pair`, or click 🌐 in the status bar (`P` in the tree). Point the phone's camera at the QR code, or type the six-digit code.

```sh
conch web pair                       # full: everything, typing into terminals included
conch web pair -permission reply     # see agents, reply, answer questions — no typing
conch web pair -permission view      # look only
conch web pair -machine busybox      # and let it reach that machine, not only this computer
```

A phone reaches this computer only until you name a machine for it. **Add it to the Home Screen** to open it like an app.

## The app

- **Agents** — what needs you first; tap an answer to a waiting agent's question.
- **Watch** — every screen at once, small and live.
- **Machines** — each machine and its projects.
- **An agent** — its output and a composer; swipe sideways for the next one.
- **＋** — a new task, agent or terminal.

## Devices

**⚙ Settings → Web → Devices…** lists paired phones, or from a terminal:

```sh
conch web devices
conch web revoke d_7h2k
conch web permission d_7h2k full -machine busybox
```

**SEEN** says `on` while the phone has the app open, else when it last reached conch web.

## Replying and answering

**A reply** is the agent's next message. **An answer** picks one of the choices of the question it is asking, shown as buttons.

## Review comments

Comments on a branch's diff show on its agent's card. **Send to the agent** hands them over as one message.

## Through a relay

Reach the laptop from any network through a relay you run; it carries the traffic without being able to read it. Run the relay yourself.

```sh
conch relay -listen :8443
```

Then point `conch web` at it in **Settings → Phone (conch web) → Relay**, or in `config.toml`:

```toml
[web]
relay = "wss://relay.example.com"
```

When you pair, check that the four words the phone shows match the ones `conch web pair` printed.
