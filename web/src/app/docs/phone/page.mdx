# Phone

`conch web` lets a phone see your agents, reply to one, and answer the question it is waiting on.

## What you need

- **Tailscale** on the laptop and the phone, signed in to the same account — or a [relay](#through-a-relay) of your own.
- **HTTPS** in front, which `tailscale serve` gives you.
- **conch** on the laptop.

## Start it

In **Conch.app**, **Settings → Phone**: set the address phones open, then **Start** on the conch web card. In the TUI, **⚙ Settings → Web** and **Start conch web**. Or from a terminal:

```sh
tailscale serve --bg http://127.0.0.1:8722
conch web -url https://laptop.tail1234.ts.net
```

`conch web stop` ends it. Every flag is on [Command line](/docs/cli#web).

## Pair a phone

In **Conch.app**, click the phone in the status bar, or **Pair a Phone…** in Settings → Phone, and choose what it may do: Full, Reply or View. In the TUI, click 🌐 (`P` in the tree), or run `conch web pair`.

Point the phone's camera at the QR code, or type the six-digit code.

```sh
conch web pair                       # full: everything, typing into terminals included
conch web pair -permission reply     # see agents, reply, answer questions — no typing
conch web pair -permission view      # look only
conch web pair -machine busybox      # and let it reach that machine, not only this computer
```

A phone reaches this computer only until you name a machine for it. **Add it to the Home Screen** to open it like an app.

## The app

- **Agents** — what needs you first; tap an answer to a waiting agent's question. **⟳2** is what one [left running](/docs/agents#left-running-in-the-background).
- **Watch** — every screen at once, small and live.
- **Machines** — each machine and its projects.
- **An agent** — its output and a composer; swipe sideways for the next one.
- **＋** — a new task, agent or terminal.

## iPhone app

**Conch for iPhone** is a native app for the same `conch web`. It is in beta and not on the App Store yet. It needs iOS 17, and conch 0.2.3 or later on the computer for the features below.

### Set it up

1. Install Tailscale on the computer and the iPhone, signed in to the same account.
2. On the computer, put HTTPS in front and start conch web:

   ```sh
   tailscale serve --bg http://127.0.0.1:8722
   conch web -url https://laptop.tail1234.ts.net
   ```

3. In another terminal on the computer, make a pairing code:

   ```sh
   conch web pair
   ```

4. In the iPhone app, tap **Scan QR code** and point it at that code. The Camera app would open the web app instead.

Without the camera, tap **Enter address & code**. Type the whole address, `https://` included, and the six digits.

The iPhone app does not pair through a [relay](#through-a-relay) yet. With a relay configured the QR code is the relay's, so use **Enter address & code** with the Tailscale address.

### What each permission allows

| To do this on the iPhone | Pair with |
| --- | --- |
| See agents, screens, projects and pull requests | `view` or more |
| Read a branch's changes, diffs and commits | `view` or more |
| See this computer's CPU and memory, and its agents' plan limits | `view` or more |
| List the artifacts Claude Code published | `view` or more |
| Reply, answer a question, leave notes on a diff and send them to the agent | `reply` or more |
| Attach a photo, video or file | `full` |
| Type into a terminal, start a task | `full` |
| Stage, commit, push, open a pull request | `full` |

A `view` phone sees the titles, links and folders of artifacts from every project on this computer.

### Attach a file

Tap the attach button beside the reply, choose the file, then send. Each file can be up to 25 MB. It is saved in `.conch/attachments/` in the agent's worktree, on the agent's machine, and git is told to ignore that folder.

### Review and ship

Open **Changes** and pick a branch. Tap a line to leave a note, and send the notes to the agent. With `full` you can also stage, commit, push and open a pull request. These run on the agent's machine with its own git, and a pull request needs `gh` signed in there.

### What it can't do yet

- **Notifications** arrive only while the app is open or was recently in the background.
- **CPU, memory and plan limits** are this computer's only, not other machines'.
- **Artifacts** come from `~/.claude` on this computer only. An agent on another machine, or on another [Claude Code account](/docs/agents#several-accounts), lists none.

### If something is missing

- **A feature says it needs a newer conch web, or fails with "no such route":** update conch, then restart the gateway with `conch web stop` and `conch web start`. A running gateway stays on the build it started with.
- **A feature fails on one machine only:** run `conch machine upgrade` for that machine.
- **A machine is absent:** pair with `conch web pair -machine NAME`, or allow it under [Devices](#devices).
- **A button is absent:** the phone's permission is lower than the table asks. Change it with `conch web permission`.

## Devices

**⚙ Settings → Web → Devices…** lists paired phones, or from a terminal:

```sh
conch web devices
conch web revoke d_7h2k
conch web permission d_7h2k full -machine busybox
```

**SEEN** says `on` while the phone has the app open, else when it last reached conch web.

## Replying and answering

**A reply** is the agent's next message. **An answer** picks one of the choices of the question it is asking, shown as buttons.

## Review comments

Comments on a branch's diff show on its agent's card. **Send to the agent** hands them over as one message.

## Through a relay

Reach the laptop from any network through a relay you run; it carries the traffic without being able to read it. Run the relay yourself.

```sh
conch relay -listen :8443
```

Then point `conch web` at it in **Settings → Phone → Relay**, or in `config.toml`:

```toml
[web]
relay = "wss://relay.example.com"
```

When you pair, check that the four words the phone shows match the ones `conch web pair` printed.
