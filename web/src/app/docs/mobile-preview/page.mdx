# Mobile preview

Your app on a real iOS simulator, beside the agent writing it — the iPhone's own screen, corners and Dynamic Island included. Conch.app, on this Mac.

## Open it

**How:** right-click a project → **Mobile Preview**, or a workbench's **Mobile** layout (⌥⌘5): files and the editor, the chat, and the phone in a column beside them. The phone button in a workbench's bar shows it in any layout.

They are offered only for a mobile app: Expo, React Native, Flutter, Xcode or Android, in the project's folder or any of its checkouts, so an app an agent is still making on its branch counts. conch looks again as files are written.

Pick the simulator from the tab's menu; **Start** boots one that is shut down, and **Run** beside it puts the app on it. A simulator that starts while the tab is open — **▶ Run** booting one of its own, or one started in Xcode — is shown, since that is where the app went.

## Simulators

A simulator keeps running after its preview is closed, until something shuts it down.

The button at the right of the tab's bar lists every simulator over the phone, running ones first: click one to show it, ⏹ shuts it down, 🗑 deletes it for good (asked first), **Shut Down All** stops them all. From a shell: [`conch preview shutdown` and `delete`](/docs/cli#preview).

## Use it

Click the screen to tap it, type in the field below it. The buttons in the bar press Home, Lock and the side button; in a narrow column Lock and the side button are under ⋯.

**▶ Run** puts the app on the phone: `npx expo start --ios`, `react-native run-ios` or `flutter run`. For an Xcode project it is `conch preview run`, which builds the app for that simulator, installs it and opens it; press it again after a change, since an Xcode app does not reload by itself.

The line above the phone names the branch ▶ runs; click it to pick another. In a workbench it is the agent's branch. When that has no app and several others do, conch asks you to pick. Outside a workbench it is the first branch with an app.

The agent's branch runs in the workbench's terminal, another in a new terminal in the sidebar.

**To agent** puts a screenshot in an agent's prompt. An agent can take one itself with [`conch preview shot`](/docs/cli#preview).

## What it needs

Xcode, for the simulators — found in Applications even when `xcode-select` points at the Command Line Tools. Tapping and typing need [AXe](https://github.com/cameroncooke/AXe) (or idb). **Settings → Mobile Preview** says where Xcode is when it is elsewhere ([`[preview]`](/docs/configuration#preview)).
