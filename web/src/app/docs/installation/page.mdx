# Installation

conch is a single binary for macOS and Linux; install it one of four ways and update it without stopping your agents.

<Callout type="note">

[Conch.app](/docs/mac-app), conch in a native macOS window, is a separate download: see [Mac app](/docs/mac-app).

</Callout>

## Install script

Installs `~/.local/bin/conch` and adds conch to your desktop's applications (`CONCH_APP=no` skips that).

```sh
curl -fsSL https://raw.githubusercontent.com/Amitgb14/conch/master/install.sh | sh
```

Add a version to install that release, including an older one:

```sh
curl -fsSL https://raw.githubusercontent.com/Amitgb14/conch/master/install.sh | sh -s -- 0.2.0
```

| Variable | Effect |
| --- | --- |
| `CONCH_VERSION=0.2.0` | install that release |
| `CONCH_INSTALL_DIR` | install into another directory |
| `CONCH_RELEASE_URL` | download from a mirror |
| `CONCH_APP=no` | don't add conch to the applications |

Then run `conch doctor` to check what conch needs. See [doctor](/docs/cli#doctor).

## With Homebrew

Includes tab completion. Update with `brew upgrade conch`, then press **u** in the version box to reload.

```sh
brew install Amitgb14/conch/conch
```

## With Go

Needs Go 1.25 or newer.

```sh
go install github.com/Amitgb14/conch/cmd/conch@latest
```

## From source

```sh
make build
```

## Shell completion

For any install but Homebrew. See [completion](/docs/cli#completion).

```sh
echo 'eval "$(conch completion zsh)"' >> ~/.zshrc
```

## Updating without stopping agents

Reload the server onto the new build; every pane keeps running.

```sh
conch server reload        # or click the version in the status bar, then r
```

## Auto-update

When a newer build or release is out, the version in the status bar shows `⬆`. Click it and press **u** to update conch, its server, the TUI and your remote machines.

`[update] auto = true` in [config.toml](/docs/configuration#update) installs releases on its own.

## Going back to an older version

```sh
conch update list        # every release, newest first
conch update rollback    # back to the version before the last update
conch update 0.2.0       # or a version you name
```
