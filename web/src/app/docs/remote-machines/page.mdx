# Remote machines

Each machine runs its own conch server, so its agents keep working when your laptop sleeps; the TUI reaches all of them over your normal `ssh`.

<Architecture />

## Adding a machine

conch probes the machine over ssh, installs itself to `~/.local/bin/conch` there if it is missing or older, and connects.

**How:** press `M` in the TUI, or:

```sh
conch machine add gpu-box      # an alias from ~/.ssh/config, user@host or ssh://user@host:port
conch machine ls
```

A host that needs a jump host, a port or other ssh options takes them in the `M` dialog's **SSH options**, or `-o Setting=value` on `conch machine add`. On a [saved ssh host](/docs/interface), `M` offers it as a machine with its options filled in.

If ssh needs a password, type it in the **Password** field; it is never saved. With **Key login** ticked (the default), conch uses it once to add your public key to the machine.

`conch machine rm ID`, `conch machine rename ID LABEL` (or `r` in the tree) and `conch machine upgrade ID` manage machines; see [Command line](/docs/cli#machine) for flags.

## Running commands on a machine

`-m` sends any command to a machine. `-cwd` is a path there and must be absolute; without it, work starts in the machine's home.

```sh
conch -m gpu-box status
conch -m gpu-box new -- make test
conch -m gpu-box task -cwd /home/dev/src/api "Fix the flaky tests"
```

No machine of your own? A [sandbox](/docs/sandboxes) is one made in the cloud.

## Machine states

| State | Meaning |
| --- | --- |
| `●` online | connected |
| `⠋` connecting | connecting |
| `○ offline` | unreachable; its panes stay visible, dimmed, while conch retries |
| `! setup` | conch needs installing or upgrading — `m` → Install |
| `outdated` | the server there predates your client — `m` → Restart server |

**How:** `R` on a machine reconnects now; `x` removes it.

## Compression

Connections to other machines are compressed, since they mostly carry pane frames.

**How:** turn it off with **Settings → Agents → Compress what a machine's panes send**. It applies to connections the next conch you start opens.

## Dropping files on a remote pane

Drag a screenshot or any file onto conch while a remote pane has focus: conch uploads it there and pastes the path on that machine. Claude Code attaches a pasted image as `[Image #1]`.

**How:** files over 25 MB are refused; change the limit or turn uploads off in Settings → Agents → Remote machines, or `[remote]` in [config.toml](/docs/configuration#remote). From a shell: `conch -m gpu-box upload FILE...`.

## Copying files to and from a machine

Use the machine's **Files** row (`U` uploads, `D` downloads) or:

```sh
conch -m gpu-box upload -to ~/certs ~/doc/ca.pem
conch -m gpu-box download -to ~/Downloads ~/logs/run.log ~/results
conch upload -ssh bb ./site                          # a terminal where you typed ssh host
```

## Moving a worktree to another machine

Move a task to a machine that stays up. conch finds or clones the project there, sends the branch's commits, staged, unstaged and untracked files, and hands each agent's conversation to the same agent there. The worktree here is kept until you remove it.

**How:** `T` on a branch or an agent in it (or `m` → **Move to another machine or a sandbox…**), pick the machine or a **New Daytona sandbox**, and confirm.

### Moving a whole project

Moves every task worktree, its agents and their conversations at once; a project with no origin is copied whole. Uncommitted changes in the main checkout and terminals stay here.

**How:** `T` on a project's row, right-click → **Move to another machine…** in Conch.app, or:

```sh
conch project move daos -to busybox        # -plan to see what would move, -y not to be asked
```

## Claude Code on a machine

**How:** `c` offers to install `claude` where it is missing, or press `C` (or `conch -m NAME agent install claude`). It runs Anthropic's installer in a pane; then `c` starts Claude, which asks you to log in on first run.

<Callout type="note">

conch never copies credentials between machines. Unattended machines can use `ANTHROPIC_API_KEY` or a `CLAUDE_CODE_OAUTH_TOKEN` from `claude setup-token`.

</Callout>
