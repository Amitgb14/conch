# The interface

The TUI shows a tree of machines, projects, branches, agents and terminals beside tabs and splits; this page covers each part.

<TuiShot id="working" title="conch" caption="The tree on the left, an agent's pane on the right." />

## The sidebar

Each machine holds `Workspace` (its projects) and `CLI` (agents and terminals of no project). Badges: `⠋1` working, `⚑1` waiting, `✓1` done.

**How:** `a` adds a project, `c` starts an agent, `n` a terminal. `!` goes to the next waiting agent.

A project that is a plain folder runs tasks in the folder itself; **Make it a git repository (git init)…** in its menu, or `conch project git-init ID|PATH`, gives tasks branches of their own.

<TuiShot id="project" title="A project" caption="A project's branches, agents and terminals." />

## Workspaces

Each workspace shows only its own projects, agents, terminals, hosts and tabs.

**How:** `+` atop the sidebar or `ctrl+b N`; `ctrl+b (` and `)` switch.

## SSH sessions

A terminal logged in to another host with your own `ssh`. Nothing is installed there.

**How:** `H`, then pick a host or type `user@host`; `y` saves it. On a saved host `K` sets up login without a password and `M` makes it a [machine](/docs/remote-machines).

## SSH folders

Group saved hosts with their sessions — `eng`, `staging`, `prod`.

**How:** `N` on `SSH`, `Agents` or `Terminals` makes a folder; drag hosts or panes into it.

## Grouped by tab

The tree lists a project's panes under the tab each is open in, as the tab bar does.

**How:** Settings → Tree grouping → By tab lists panes under their tab.

## Git panel

Type git commands that run in a branch's worktree.

**How:** `b` or `$` on a branch; `tab` lists everyday actions. With an agent on the branch, `ctrl+t` sends what you type to it instead.

## Changes view

Selecting a branch shows its pull request, files and diffs, following the agent's edits live.

<TuiShot id="diff" title="Changes" caption="A branch's diff, side by side." />

| Key | |
| --- | --- |
| `a` / `S` | comment / send comments to the agent |
| `c` / `p` | commit / push and open a PR |

All keys: [Keys and mouse](/docs/keys).

## Review queue

What needs a decision, across machines: waiting agents, failed checks, finished work.

**How:** `Q`; `enter` opens a row, `v` runs the check.

<TuiShot id="queue" title="Review queue" caption="What needs you, most urgent first." />

### Sending a failure back

`f` on a failed row sends the failure to the branch's agent. `[verify]` automates it:

<AutopilotLoop />

```toml
[verify]
auto_fix = 2         # send a failed check back up to twice
auto_pr = true       # push a finished branch and open its pull request
auto_merge = true    # merge a pull request when it turns green
auto_resolve = 2     # bring a conflicting branch up to date
```

A pull request conch saw open with no checks yet, or green at a commit since replaced, merges once it turns green while conch watches.

### A second opinion

A reviewer reads each finished branch; `R` hands its report to the writer.

```toml
[verify]
reviewer = "codex"
```

## Files

Every project has a **Files** row: a checkout with each file's git status and a preview.

**How:** `f` browses a branch's worktree; `a` types a file's path into the agent's prompt, `d` shows its diff, `e` opens it in `$EDITOR`.

### A machine's own files

A remote machine, and a terminal running `ssh host`, get a **Files** row of their own, which also copies files between there and here.

**How:** `f` on a remote machine or ssh terminal; `U` uploads, `D` downloads.

## Splits and tabs

Tabs work like tmux windows: every agent and terminal gets its own tab, and each tab can be split.

| Keys | |
| --- | --- |
| `ctrl+b %` / `ctrl+b "` | split right / down |
| `ctrl+b c`, `n`, `p` | new, next, previous tab |
| `ctrl+b z` | zoom |
| `ctrl+b /` | palette |
| `ctrl+b d` | detach (agents keep running) |

All keys: [Keys and mouse](/docs/keys).

## Scrollback and copying

Every pane keeps 10,000 lines of history, an agent's pane included.

**How:** the wheel scrolls; drag copies. `ctrl+b [` enters scroll mode: `/` searches, `v` selects, `y` copies.

## Watching a pane

Alerts for a pane that is not an agent — a build, a test run, a log.

**How:** `ctrl+b M` alerts when a pane goes quiet, `ctrl+b A` when it prints.

## Links an agent printed

A login URL an agent wrapped inside its box, put back together and opened in this computer's browser.

**How:** `ctrl+b u` opens and copies a link, rewrapped whole; or alt-click it.

## Settings

Theme, notifications, agents, sandboxes and the rest.

**How:** `,` or `⚙`. Saved to `config.toml`: [Configuration](/docs/configuration).

### Edit in browser

Every setting in `config.toml` as a form in your browser.

**How:** `e` in Settings, or `conch config web`.

### Notifications

A notification, sound or beep when an agent waits or finishes, or a plan limit is nearly used.

**How:** `,` → Notifications: when, how, quiet hours.
