# Configuration

conch keeps its socket, state and settings in one directory. Most settings can be changed from the Settings screen (`,`), which writes `config.toml` for you.

## Files

Everything lives in `~/.config/conch`. Set `CONCH_HOME` to use another directory; without it, conch uses `$XDG_CONFIG_HOME/conch` when `XDG_CONFIG_HOME` is set.

| File | Contents |
| --- | --- |
| `conch.sock` | the server's socket (override with `CONCH_SOCKET`) |
| `server.log` | the server's log |
| `projects.json` | the projects in the sidebar |
| `claude-settings.json` | the hooks conch passes to Claude Code with `--settings` |
| `ui.json` | fold state, sidebar width, tabs and splits |
| `machines.json` | remote machines: only an ID, label and ssh target |
| `ssh/config` | generated ssh config |
| `binaries/<os>-<arch>/conch` | conch builds for other platforms |
| `agents/claude.toml` | optional override of Claude's [screen rules](/docs/agents#how-the-state-is-decided) |
| `config.toml` | your settings |

## Environment variables

| Variable | Effect |
| --- | --- |
| `CONCH_HOME` | the directory above |
| `CONCH_SOCKET` | the server socket path |
| `CONCH_SOURCE` | conch's source tree, for cross-compiling to [remote machines](/docs/remote-machines#adding-a-machine) |
| `CONCH_REMOTE_BINARY` | a prebuilt conch binary to install on remote machines |
| `CONCH_VERSION`, `CONCH_INSTALL_DIR` | release and directory for the [install script](/docs/installation#install-script) |

## config.toml

A `config.toml` conch cannot read never keeps you out: it starts on the defaults and says what was wrong with the file, in the TUI as a message on start-up and on the terminal for `conch ask`. Saving from the Settings screen then keeps the file that could not be read as `config.toml.invalid`, so a half-finished edit is never written over.

All keys with their defaults:

```toml
[keys]
prefix = "ctrl+b"

[pane]
default_command = ""   # empty = $SHELL

[notify]
enabled = true
desktop = true   # macOS notification / notify-send
sound = false    # system sound
bell = false     # terminal beep
waiting = true   # when an agent needs an answer
done = true      # when an agent finishes
quiet_start = "" # quiet hours, e.g. "22:00"
quiet_end = ""   # e.g. "08:00"
limits = true    # when a Claude or Codex plan limit window is nearly used
limit_at = [80, 95] # percent used that alerts
silence = 30     # seconds without output before a watched pane (ctrl+b M) alerts

[ui]
mouse = true
theme = "conch"  # conch, dracula, catppuccin, nord, gruvbox, tokyo-night, one-dark, solarized,
                 # rose-pine, kanagawa, everforest, monokai, github-dark, ayu, night-owl
accent = ""      # override: teal, blue, green, orange, pink, red, gray, purple or "#rrggbb"
cost = true      # show what agents spend in the tree, Sessions and the pages
icons = "text"   # file explorer icons: text (letters, any font), nerd (Nerd Font glyphs) or off

[shell]
omz_theme = ""   # Oh My Zsh theme for new zsh terminals; "" keeps .zshrc's

[agents]
default = "claude"  # what c starts: claude, codex, gemini, opencode

[brain]
provider = "claude"  # claude, anthropic or openai
model = ""
summary_model = ""
summaries = false

[update]
check_releases = true  # ask GitHub once a day for a newer release
auto = false           # and install it as soon as it is found

[remote]
upload_drops = true    # upload files dropped on a remote pane and paste their paths there
upload_max_mb = 25     # refuse larger files (the server takes at most 256)
```

### notify

`quiet_start` and `quiet_end` (`"HH:MM"`) silence alerts every day between them; the range may wrap past midnight. Waiting agents still show in the sidebar. Leave either empty for no quiet hours.

`silence` is how long a pane watched with `ctrl+b M` must go without output before it alerts; see [Watching a pane](/docs/interface#watching-a-pane). Less than 1 means the default, 30.

`limits` alerts when Claude's 5-hour or weekly window, Codex's windows or a spend limit passes a percentage in `limit_at` (1–100). Each threshold alerts once per window and machine, even across restarts of the TUI; a new window after a reset alerts again.

### ui

`mouse = false` leaves the mouse to your terminal entirely. With it on, hold shift (option in iTerm2) to select text with the terminal instead.

### brain

The model behind `:` and agent summaries. `[brain]` also takes `base_url`, `api_key_env` and `command`; see [Brain](/docs/brain#configuration).

### update

`check_releases` asks GitHub once a day whether a newer release exists (release builds only). `auto = true` installs what that check finds without waiting for **u**, and reloads the local server onto it; it needs `check_releases`. `conch update rollback` goes back. See [Auto-update](/docs/installation#auto-update).

### remote

`upload_drops` uploads local files dropped (pasted as paths) on a remote machine's pane to that machine and pastes their paths there; `false` pastes the local paths unchanged. `upload_max_mb` is the largest file uploaded. See [Dropping files on a remote pane](/docs/remote-machines#dropping-files-on-a-remote-pane).

<Callout type="note">

The Settings screen rewrites `config.toml`, so comments in a hand-edited file are not preserved.

</Callout>
