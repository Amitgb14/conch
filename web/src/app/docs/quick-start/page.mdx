# Quick start

From installing conch to several agents working in parallel, each on its own branch.

## Your first session

<Steps>

<Step title="Install conch">

```sh
curl -fsSL https://raw.githubusercontent.com/Amitgb14/conch/master/install.sh | sh
```

Other ways are on [Installation](/docs/installation). `conch doctor` checks what conch needs.

</Step>

<Step title="Open the TUI">

```sh
conch
```

The first run starts the server. `?` lists every key.

</Step>

<Step title="Add a project">

Select `local` and press `a`, pick a folder and press `a` again. Or `conch project add PATH`.

</Step>

<Step title="Start an agent here">

Press `c` then `enter` to start your default agent in the project. `ctrl+b` then any key returns to the tree.

</Step>

<Step title="Start a task on its own worktree">

Press `t` on the project and describe the work. conch makes a branch and worktree and starts the agent there. See [Tasks and worktrees](/docs/tasks).

```sh
conch task -cwd ~/src/api "Add a health check endpoint"
```

</Step>

<Step title="Watch the agents">

`⠋` working, `!` waiting for you, `✓` done, `○` idle. Press `!` to jump to the next waiting agent, and `B` to tell several agents the same thing.

</Step>

<Step title="Review a branch">

Select a branch to see its changes. `enter` on a file shows its diff, `o` opens the pull request, `x` removes the worktree.

</Step>

<Step title="Detach and come back">

Press `q` to detach; agents keep running. Run `conch` again to come back.

<Callout type="warning">

`conch server stop` stops the server **and every pane it owns**.

</Callout>

</Step>

</Steps>

## Going further

<Steps>

<Step title="Add a remote machine">

Press `M`, or run `conch machine add gpu-box`. See [Remote machines](/docs/remote-machines).

</Step>

<Step title="Ask the brain">

Press `:` and say what you want. Nothing runs until you press enter. See [Brain](/docs/brain).

</Step>

</Steps>
