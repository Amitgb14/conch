Run a fleet of coding agents from one terminal

conch is a terminal orchestrator for Claude Code, Codex, Gemini CLI and OpenCode. A background server owns their terminals, so agents keep working when you close the UI — on your laptop or on any machine you can ssh into.

curl -fsSL https://raw.githubusercontent.com/Amitgb14/conch/master/install.sh | sh

macOS and Linux, amd64 and arm64 · or go install github.com/Amitgb14/conch/cmd/conch@latest

Everything your agents are doing, in one tree

Machines, projects, git branches, agents and terminals sit beside a live view of whatever you select.

⠋Agents that outlive the UI

A server owns every pane. Detach with q, close your laptop, come back later — the work kept going.

!Know who needs you

Working, waiting, done or idle for every agent, from hooks and screen rules. Desktop notifications, quiet hours and snooze.

◇One worktree per task

Press t and describe the task: conch makes a branch and worktree, copies your .env and local settings, and starts the agent.

●Remote machines over ssh

Add any host from your ssh config. conch installs itself there, and its server keeps agents running when your network drops.

#Git and pull requests

Uncommitted lines, commits ahead and behind, conflicts, PR checks and reviews — plus a changes view with diffs for every branch.

✦Ask in plain words

"Start 3 agents on api: …" becomes a checked plan of tasks and messages. Nothing runs until you press enter.

↺Sessions and resume

Every saved conversation for a project, across agents. Resume one with enter, or all runs a server stop interrupted with I.

$Token usage

Context, output and cost in each agent's title bar, read from the agent's own session data — never estimated.

▦Splits, tabs and themes

tmux-style splits and tabs, scrollback with copy mode, mouse support, and six colour schemes.

Bring the agents you already use

conch never edits an agent's configuration or answers its trust prompts. Missing an agent on a machine? Install it from the same menu — no root needed.

Claude Code

State from hooks, the screen and the transcript.

Gemini CLI

OpenCode

State from plugin events and the screen.

Scriptable from the shell

Every action in the TUI is a command, locally or on a machine with -m. The server speaks newline-delimited JSON over a unix socket.

# a branch, a worktree and an agent
conch task -cwd ~/src/api "Add a health check endpoint"

# the same on a remote machine
conch -m gpu-box task -cwd ~/src/api "Fix the flaky tests"

conch status              # panes with agent state
conch read p1             # visible screen as text
conch send p1 "also cover logout" && conch send -keys p1 enter
conch ask "what is waiting for me?"
